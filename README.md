# EARFQUAKE: анализатор землетрясений

Скачивает сейсмограммы с сервера FDSN (obspy), убирает инструментальный отклик
и обрабатывает их в C#: фильтрация, FFT, спектр.

## Запуск готовой программы (Windows)

1. Открой раздел **Releases** справа на странице репозитория.
2. Скачай `EARFQUAKE-win-x64.zip`.
3. Распакуй архив (правый клик → «Извлечь всё»).
4. Запусти `EARFQUAKE.exe`.

Python, .NET и obspy устанавливать не нужно. Для скачивания данных нужен интернет.
Windows может показать предупреждение SmartScreen: нажми «Подробнее» → «Выполнить в любом случае».

## Запуск из исходников

1. Установи Python 3.10+ и .NET SDK.
2. `pip install obspy`
3. Открой решение в Visual Studio и запусти проект.

## Структура

- `EARFQUAKE/`: C#-проект (чтение данных, обработка)
- `python/SacProcessor.py`: загрузка и подготовка данных (obspy)
- `build.ps1`: сборка готового архива для пользователей
